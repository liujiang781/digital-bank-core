# 身份认证风控与运营用例表

用例编号、参与者和优先级与[主报告](实验一需求规格说明书.md)对应。运营参与的账户和交易用例沿用[账户模块用例表](数字银行账户与交易模块需求分析/02-账户模块用例说明.md)及[交易模块用例表](数字银行账户与交易模块需求分析/03-交易模块用例说明.md)。

## 身份与认证模块

### UC-ID-01 注册与实名认证

| 项目 | 内容 |
| --- | --- |
| 用例标识和名称 | UC-ID-01 注册与实名认证 |
| 描述 | 建立客户身份与模拟实名记录 |
| 参与者 | 客户 |
| 优先级 | P0 |
| 非功能需求 | NFR-06、NFR-07、NFR-09 |
| 前置条件 | 客户可访问注册入口 |
| 触发条件 | 客户提交注册资料 |
| 主事件流 | 校验资料与请求标识，创建客户和登录凭据，记录模拟实名结果 |
| 可选事件流 | 资料无效或身份已存在时给出相应反馈。同号同内容复用原结果，同号异内容返回冲突 |
| 后置条件 | 注册成功后可使用新身份登录。失败时不增加重复客户记录 |

### UC-AU-01 登录系统

| 项目 | 内容 |
| --- | --- |
| 用例标识和名称 | UC-AU-01 登录系统 |
| 描述 | 建立已认证会话 |
| 参与者 | 客户、系统管理员、运营人员、风控专员、授权审批人 |
| 优先级 | P0 |
| 非功能需求 | NFR-01、NFR-06、NFR-07、NFR-09 |
| 前置条件 | 已具备有效身份和登录凭据 |
| 触发条件 | 参与者提交登录凭据 |
| 主事件流 | 校验身份与凭据，建立会话并返回角色与授权信息 |
| 可选事件流 | 身份、凭据或用户状态不符时拒绝，会话过期后需重新登录 |
| 后置条件 | 成功时建立会话，受保护功能按会话权限开放 |

### UC-ID-03 维护个人资料

| 项目 | 内容 |
| --- | --- |
| 用例标识和名称 | UC-ID-03 维护个人资料 |
| 描述 | 查询或更新本人可修改的资料 |
| 参与者 | 客户 |
| 优先级 | P1 |
| 非功能需求 | NFR-01、NFR-03、NFR-09 |
| 前置条件 | 客户已登录 |
| 触发条件 | 客户查看个人资料或提交修改 |
| 主事件流 | 定位本人资料并脱敏展示。收到修改时校验手机号、邮箱与请求标识，保存允许变更的字段 |
| 可选事件流 | 无效联系方式或不允许修改的身份字段被拒绝 |
| 后置条件 | 本人可查询生效后的资料，身份及账户归属保持原有记录 |

### UC-AU-02 管理角色与权限

| 项目 | 内容 |
| --- | --- |
| 用例标识和名称 | UC-AU-02 管理角色与权限 |
| 描述 | 分配岗位角色与数据范围 |
| 参与者 | 系统管理员 |
| 优先级 | P1 |

## 风控模块

### UC-RK-01 配置风控规则

| 项目 | 内容 |
| --- | --- |
| 用例标识和名称 | UC-RK-01 配置风控规则 |
| 描述 | 维护生效的风控规则 |
| 参与者 | 主要为风控专员，审批为授权审批人 |
| 优先级 | P1 |
| 非功能需求 | NFR-01、NFR-03、NFR-10、NFR-12 |
| 前置条件 | 参与者具有相应岗位权限，目标规则存在 |
| 触发条件 | 风控专员提交规则变更 |
| 主事件流 | 记录申请，另一授权身份审批，通过后生效并保留版本及审批记录 |
| 可选事件流 | 越权、自审或参数无效时拒绝。审批驳回时保留原规则 |
| 后置条件 | 变更状态、实际规则版本和审批信息可追溯 |

### UC-RK-02 维护风险名单

| 项目 | 内容 |
| --- | --- |
| 用例标识和名称 | UC-RK-02 维护风险名单 |
| 描述 | 审核并维护风险名单条目 |
| 参与者 | 主要为风控专员，审批为授权审批人 |
| 优先级 | P1 |
| 非功能需求 | NFR-01、NFR-03、NFR-10 |
| 前置条件 | 参与者拥有岗位权限及必要的对象范围 |
| 触发条件 | 风控专员提交名单变更 |
| 主事件流 | 校验名单类别与对象，登记申请，由另一授权身份审批，通过后更新条目并留痕 |
| 可选事件流 | 未授权对象、自审或无效申请被拒绝。驳回后原条目继续生效 |
| 后置条件 | 名单的有效状态、申请和审批记录可查询 |

### UC-RK-03 处置风险告警

| 项目 | 内容 |
| --- | --- |
| 用例标识和名称 | UC-RK-03 处置风险告警 |
| 描述 | 记录风险事件的人工结论 |
| 参与者 | 风控专员 |
| 优先级 | P2 |
| 非功能需求 | NFR-01、NFR-03、NFR-10 |
| 前置条件 | 风控专员已登录且能访问关联账户，风险事件已登记 |
| 触发条件 | 风控专员提交处置结论与依据 |
| 主事件流 | 验证范围、事件和请求标识，登记处置并关联原交易和审计 |
| 可选事件流 | 缺少依据或越权时拒绝。同键同内容重放返回原结果，同键异内容返回冲突 |
| 后置条件 | 处置结果与原事件及交易可追溯 |

### UC-RK-04 查询风险记录

| 项目 | 内容 |
| --- | --- |
| 用例标识和名称 | UC-RK-04 查询风险记录 |
| 描述 | 查看业务范围内的规则命中事件 |
| 参与者 | 风控专员、授权运营人员 |
| 优先级 | P1 |
| 非功能需求 | NFR-01、NFR-03、NFR-09 |
| 前置条件 | 参与者已登录并拥有对象范围 |
| 触发条件 | 参与者填写查询原因并发起查询 |
| 主事件流 | 检查角色与对象范围，按筛选条件返回命中、原因与交易编号，记录查询 |
| 可选事件流 | 权限、范围或查询参数不符时拒绝 |
| 后置条件 | 仅显示授权事件并保留查询记录 |

## 运营模块

### UC-OP-01 查看客户列表

| 项目 | 内容 |
| --- | --- |
| 用例标识和名称 | UC-OP-01 查看客户列表 |
| 描述 | 在授权范围内查看客户和账户状态 |
| 参与者 | 运营人员 |
| 优先级 | P1 |
| 非功能需求 | NFR-01、NFR-03、NFR-09 |
| 前置条件 | 运营人员已登录且拥有数据范围 |
| 触发条件 | 运营人员填写原因并请求客户列表 |
| 主事件流 | 校验角色与范围，分页返回授权客户与账户状态，按权限展示资料并留审计 |
| 可选事件流 | 缺少原因或超越角色权限时拒绝。无匹配客户时返回空结果 |
| 后置条件 | 返回符合授权条件的客户资料，保留查询记录 |
