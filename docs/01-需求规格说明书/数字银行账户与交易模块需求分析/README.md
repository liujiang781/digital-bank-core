# S2 账户与交易模块完整成果

建议先阅读 [S2账户与交易需求分析完整稿.md](S2账户与交易需求分析完整稿.md)。该文件汇总规则、用例、异常及图表，适合发给组长和组员评审。

## 内容

- 账户九个基本用例、交易九个基本用例，均有详细描述。
- 十四条用户故事和故事—用例映射，供 Backlog 和用户故事地图使用。
- 账户二十条异常汇总，存款十三条、取款十二条、行内转账十二条、跨行转账十四条异常，共七十一条。
- 账户与交易各一张用例图，四个核心业务各一张活动图，提供 PNG 和可编辑 PlantUML 源文件。
- 资金、额度、账户及交易状态规则，具体验收预期、组员交接与 AI 使用说明。

## 交给组长时

将完整稿及 diagrams 文件夹一起发送，或者直接发送同级目录下的成果压缩包，保证文档中的图片可用。独立源文件方便分工修改；调整规则时同步修改相关用例、异常和图。

本稿是有具体建议规则的完整需求方案。账户数量、限额、时间参数、优先级等尚需小组确认；各处验收数据是预期，不是实际测试结果。S2 和组员仍需按老师要求进行人工核对、修改，并保留真实 Git 过程。

本成果完整覆盖 S2 的账户、交易分析，不代替 S3 的完整风控用例、S4 的整张用户故事地图或 S5 的最终领域模型。

## 图源工具

图表使用 PlantUML 本地生成。可在支持 PlantUML 的工具中打开 `.puml` 修改，再导出图片；PNG 可直接插入实验报告。工具参考 [官方说明](https://plantuml.com/starting) 和 [命令行说明](https://plantuml.com/command-line)。成果压缩包只包含文档、图源与图片，不包含绘图工具程序。
