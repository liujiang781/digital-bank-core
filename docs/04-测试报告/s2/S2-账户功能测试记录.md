## 1. 等价类划分

| 输入域 | 有效类 | 无效或业务拒绝类 |
|---|---|---|
| 开户请求 | 本人、已实名、CNY；未注销账户数小于 3；同一请求重放 | 已有 3 个未注销账户；请求头与请求体 UUID 不一致 |
| 账户访问 | 本人查看；工作人员具有目标账户范围 | 无会话、伪造身份头、访问他人账户 |
| 冻结与解冻 | 有范围的运营或风控可冻结；有范围的运营提供全部有效限制编号可解冻 | 普通客户冻结；风控解冻；遗漏限制编号 |
| 注销 | 账面余额和预留均为零，无未决交易 | 有账面余额、有预留、存在未决交易。有效存储数据满足 `R ≤ B`，有预留用例同时具有正账面余额 |
| 存款记账 | 已受理原单的有效回执；成功回执重放 | 金额 JSON 类型错误、缺内部令牌、原单要素或回执冲突。明确失败、未决是合法回执，其资金效果均为零 |
| 内部出账 | 账户侧逐笔预留后结算；有明确失败依据时释放 | 无预留直接提交；第二条流水写入失败时整笔回滚 |
