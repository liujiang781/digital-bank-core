# S5 测试脚本说明

本目录有两份脚本。脚本只使用真实服务和真实数据库，不内置模拟业务响应。

## 1. `s5_e2e.py`：接口端到端

只用 Python 标准库。请求经网关，响应 JSON 直接写入证据目录。令牌与口令不写入证据。

参数如下。

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--base-url` | http://127.0.0.1:8090 | 网关地址 |
| `--tx-base` | 空 | 交易服务直连地址。填写后才执行渠道三态 |
| `--user` | UID-000001 | 登录身份 |
| `--password` | demo123 | 登录口令 |
| `--other-user` | UID-000002 | 越权查询用的另一身份 |
| `--account` | ACC-0001 | 主测试账户 |
| `--to-account` | ACC-0002 | 本行转账收款账户 |
| `--low-account` | 空 | 已有的低余额账户。留空则新开账户 |
| `--out` | 必填 | 证据输出目录 |

渠道三态需要环境变量 `S5_INTERNAL_TOKEN`。令牌至少 32 字节。服务启动时也要用同一个值。网关不路由内部路径，所以脚本直连交易服务的 8083 端口。

脚本按期望输出自动判定结果。判定只比较 HTTP 状态、业务码和 `data.status`。人工复核仍然需要看输入和数据库快照。

## 2. `s5_page_test.py`：页面测试

依赖 `websocket-client`。脚本启动 Edge 无头浏览器，用远程调试协议操作页面。

参数如下。

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--edge` | 必填 | Edge 可执行文件绝对路径 |
| `--url` | http://127.0.0.1:5173 | 前端开发服务器地址 |
| `--out` | 必填 | 证据输出目录 |
| `--user` | UID-000001 | 登录身份 |
| `--password` | demo123 | 登录口令 |

脚本覆盖六个页面用例。存款提交需要选择账户和点击二次确认。脚本会完成这两步。页面判定基于 URL 变化和页面文本。交易是否只入账一次仍由接口脚本证明。

## 3. 启动脚本

仓库根目录的 `scripts/s5-local-stack.sh` 从 `logs/_*.cmd` 读取本机环境变量，然后启动五个后端服务和网关。它不把口令写入仓库。设置 `S5_INTERNAL_TOKEN` 后，交易服务会开启渠道演示内部接口。

服务退出后，脚本会按 PID 文件停止所有子进程。
