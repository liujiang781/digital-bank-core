## 写作通用要求

1. **图文对应**：正文提到"如图 2-3 所示"就必须有编号图，图题写在图下方。
2. **表格编号**：`表1-1`、`表2-1` 按章编号，不要跨章乱编。
3. **术语一致**：账户、客户、交易流水、风控规则等术语全篇统一，中英文对照第一次出现时标注。
4. **不用截图代替图**：UML 图必须同时提交 `.puml` 源文件，图中不能有水印、不能有中文乱码。
5. **AI 产出要标记**：任何 AI 生成后人工修改的内容，在 `05-实验总结/AI使用记录.md` 登记，报告中相应位置注明。

## 提交前总检查

- [ ] 五个部分齐全，页码、目录与正文一致
- [ ] 所有图表有编号和题注，正文有引用
- [ ] UML 源文件与导出图同名、都在 `docs/uml/`
- [ ] 组内互评表、AI 使用记录已填，且与 Git 提交记录对得上
- [ ] 打印版排版无跨页断图、表格不超出页边距
